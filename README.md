# Snapchat-Style Face Filters 🎭

A Python-based face filter application inspired by Snapchat, built using OpenCV and MediaPipe.

The application detects facial landmarks in real time using a webcam and applies different fun filters to the user's face.

## ✨ Features

- 🕶️ Sunglasses Filter
- 👨 Moustache Filter
- 👑 Crown Filter
- 🐱 Cat Filter
- 🐰 Bunny Filter
- 🌸 Flower Filter
- ❌ OFF Button to remove filters
- 📸 PHOTO Button to capture and save photos

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## 📦 Installation

1. Clone this repository:

```bash
git clone https://github.com/vrishteacreates/snapchat-filters.git
```

2. Open the project folder:

```bash
cd snapchat-filters
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python sunglasses.py
```

Make sure your webcam is connected and accessible.

## 📸 Photo Capture

Click the PHOTO button to capture an image. Captured photos are saved in the `captures` folder.
